# キャラ2の全イラスト・元絵の髪を再現

- 追加依頼：添付1枚目に比べて広がった髪を元絵に忠実に戻す。ポーズと表情はすべて現在の各画像のまま。
- 髪の基準：hair-reference.png（添付1枚目と参考イラスト/キャラ2/服装/01.pngはSHA-256一致）。添付2枚目は修正対象のカード持ち。
- 対象8枚：special・rank1〜4（各1024角）、cards（1038×1515）、icon・icon_game（各256角）。icon_gameは修正したiconから既存の位置基準で派生。
- 髪の横への膨張、余分な束・外跳ね・ループを元絵の輪郭・束数・下向きの流れに戻す。元絵本来の細い束と境界は残す。顔の幅を縮めて代用しない。
- 各画像の表情・頭の角度・顔と体の大きさ・服・手・小物・ポーズは保つ。必要に応じて変更外を元画像から再利用し、保護範囲を記録。
- 内蔵image_genで1枚ずつ、毎回元絵を参照。保存・比較してから次へ進む。原本と使用中素材は保持し、候補を別保存。今回の依頼は再生成までで、ゲームへの置換・公開は行わない。
- 数値検査：寸法、実透過、500KB以下、保護画素と原本ハッシュ、8枚ZIP。目視検査：髪の輪郭・束・毛先、全ポーズと表情、明暗背景、元絵の髪と顔の比率。

## 意図確認用の要約
キャラ2の全ポーズを変えず、髪だけを1枚目の元絵のコンパクトなボブへ戻す。元絵の表情や立ち方を他の絵へコピーしない。元の使用中素材を残し、新しい8枚を確認用へ保存する。
