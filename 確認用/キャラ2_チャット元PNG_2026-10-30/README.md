# チャットに表示した生成直後の元PNG

- 保存で避けられない画質低下ではなく、前の納品用PNGは500KB以下にする縮小・色数削減と、元の表情・体を保つ加工をしていました。
- このフォルダは生成直後の7枚をそのままコピーしたものです。縮小・色数削減・再生成は行っていません。チャットに出した元ファイルとのSHA-256一致を確認しています。
- special・rank1〜4・cards・iconの7枚です。元画像の寸法と色・透明度のままです。icon_gameは生成画像から作る派生素材なので含めていません。
- 表情や体を元画像に戻す合成・ゲーム用の寸法合わせより前の画像です。そのため、以前の納品用8枚とは細部やサイズが異なります。
- 元PNG7枚.zipにはPNGだけが入っています。原本・既存の納品用画像・アプリは変更していません。
- 対応と検査は元PNG対応表.jsonを参照。
